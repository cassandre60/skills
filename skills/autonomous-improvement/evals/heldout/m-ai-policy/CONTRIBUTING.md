# Contributing

## AI-contribution policy

This repository does not accept AI-generated code contributions. Pull
requests whose diffs are written in whole or in part by an AI agent will be
closed. Tool-assisted *reports* are welcome: issues that describe a defect,
include reproduction steps, and cite the file and line are appreciated and
will be triaged by a human maintainer.

Code contributions must be human-authored and signed off with `git commit -s`.
